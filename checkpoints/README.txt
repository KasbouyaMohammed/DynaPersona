DynaPersona-MoE checkpoints

The validation-selected DynaPersona-MoE checkpoints for seeds 42, 123, and 7 are not stored in this repository. They are available from the corresponding author on reasonable request.

The repository contains the training and evaluation code, per-seed result files, aggregate summaries, parameter-counting utility, table-regeneration script, and figure-generation script used to check the reported computational results.
